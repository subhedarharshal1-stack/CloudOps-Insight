# CloudOps Insight

### AWS Monitoring, Security & Cost Optimization Platform

## Project Overview

CloudOps Insight is a Python-based application that helps users monitor their AWS resources through a centralized dashboard.

The project focuses on collecting AWS resource information, identifying selected security issues, and providing recommendations for potential cost optimization.

## Technologies Used

* AWS EC2
* AWS S3
* AWS EBS
* AWS CloudWatch
* AWS IAM
* Python
* Boto3
* Streamlit
* Pandas
* Plotly
* Git and GitHub

## Main Features

1. AWS resource monitoring.
2. EC2 instance information.
3. S3 bucket monitoring.
4. EBS volume monitoring.
5. CloudWatch metrics visualization.
6. Basic cloud security checks.
7. Potential cost optimization recommendations.
